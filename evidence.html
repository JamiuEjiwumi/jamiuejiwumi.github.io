01 / RELEASE ENGINEERING

Build once, promote the same digest

An immutable application build is tagged with a commit SHA and deployed by digest to controlled environments. Promotion must not rebuild the artifact, while approvals and post-deployment health checks govern release safety.

Commit→CI build & tests→Registry digest→Dev→UAT→Production

02 / IDENTITY ARCHITECTURE

Cross-cloud access without static keys

Azure workload identity obtains a trusted assertion, exchanges it for scoped temporary AWS credentials, then signs only authorised API requests. The example highlights trust claims, least privilege and credential lifetime.

Azure identity→OIDC assertion→AWS STS→Scoped role→SigV4 API

03 / PLATFORM ENGINEERING

Module ownership with safe boundaries

Platform engineering owns tested and versioned module contracts while applications own Terraform roots, remote state and approved changes. Planning roles should not inherit apply permissions by default.

Platform modules→App A root + stateApp B root + state→Reviewed plan / apply
